# External source notices

The inference integrations use code obtained from the model authors' repositories.
Compatibility patches preserve their source notices. Source revisions and URLs
are specified in each model's YAML file.

| Project | Source license |
| --- | --- |
| [Dispider](https://github.com/Mark12Ding/Dispider/blob/8b03eda448993f491b3237f8d511ace654c0af23/LICENSE) | Apache-2.0 |
| [StreamForest](https://github.com/MCG-NJU/StreamForest/blob/f9d14670ff451ff5865638e17c9958e99bf2fec5/LICENSE) | Apache-2.0 |
| [MMDuet2](https://github.com/yellow-binary-tree/MMDuet2/blob/7bd91d5239adcb273df0977bc6c23faff950912c/LICENSE) | Apache-2.0 |

| [VideoLLM-online](https://github.com/showlab/videollm-online/blob/cfbd7ce808a9ec666264b704a73c5db596705098/LICENSE) | Apache-2.0 |
| [SimpleStream](https://github.com/EvolvingLMMs-Lab/SimpleStream/tree/be227ee8ce90a258b286a34161688c2a59eeeadb) | Refer to the upstream project for its terms |

Model checkpoints and their base models have their own terms, including the
Llama 3 terms for VideoLLM-online. The source setup command obtains model code;
checkpoints are obtained separately from their authors.
